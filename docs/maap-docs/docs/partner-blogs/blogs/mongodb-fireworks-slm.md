# You don't need a Frontier Model to do RAG with MongoDB Atlas

This project aims to build and leverage task-specific Small Language Models (SLMs) in Fireworks.ai platform. MongoDB will be leveraged for generating task-specific datasets and as a Retrieval Augmented Generation (RAG) component to provide contextual knowledge. By integrating MongoDB with Fireworks.ai, the SLM can be fine-tuned on diverse use cases and datasets and incorporate relevant information during inference, leading to improved performance in various applications like customer support, content generation, data analysis, and language translation.

## Key Topics Covered

- Task-specific SLMs with Fireworks.ai
- Dataset generation using MongoDB
- Retrieval Augmented Generation (RAG)
- Fine-tuning SLMs for diverse use cases
- Real-world application scenarios
